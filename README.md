# 🌿 린다이어트 양약 복용 판정기 (LeanDiet Drug Checker)

다이어트 한약 처방 시 환자가 복용 중인 양약의 성분을 즉각 분석하여 **병용 가능 / 병용 주의 / 병용 불가** 여부와 임상 연구진 의견을 실시간으로 판정해 주는 한의원 전용 초고속 웹 애플리케이션입니다.

👉 **웹 바로가기**: [https://junesight.github.io/leandiet-drug-checker/](https://junesight.github.io/leandiet-drug-checker/)

---

## ✨ 주요 기능

- 🔍 **초고속 검색 & 초성 검색 지원**: `탁센`, `타이레놀`, `ㅌㅅ`, `ㅍㅋ` 등 약품명 및 초성 입력 시 0.01초 즉시 자동 완성
- 🚦 **3단계 명확한 시각적 판정**:
  - 🔴 **병용 불가 (금기)**: 67종 핵심 성분 매칭 시 붉은색 경고 및 연구진 상세 소견 출력
  - 🟡 **병용 주의**: 100여 종 주의 성분 매칭 시 노란색 안내 및 복약 가이드 출력
  - 🟢 **병용 가능**: 단독 안전 성분 등 병용 가능한 약물 안내
- 📋 **식약처 공공데이터 연동 & 오프라인 하이브리드 지원**: 네트워크 지연 없이 대표 처방/일반의약품 150+종 및 160+종 금기/주의 성분 내장
- 📱 **모바일/태블릿 반응형 UI**: 진료실 PC, 상담실 태블릿, 스마트폰 등 어디서나 최적화된 구글 스타일 미니멀 검색 UI

---

## 🛠️ 기술 스택

- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript, Lucide Icons
- **Data**: 식약처(MFDS) 공공데이터포털 e약은요 API 연계 + 린다이어트 한의학/약학 연구진 DB
- **Deployment**: GitHub Pages / Vercel

---

## 🚀 시작하기

### 로컬 실행
`index.html` 파일을 브라우저로 열거나 `start_app.bat`을 더블 클릭하여 즉시 실행할 수 있습니다.
